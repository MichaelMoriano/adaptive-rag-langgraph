# Adaptive RAG con LangGraph 🤖

Bienvenido al sistema de **Retrieval-Augmented Generation Adaptativo**.

Este agente:
- 🔍 Detecta si tu pregunta necesita documentos internos o búsqueda web
- 📊 Evalúa la relevancia de los documentos recuperados
- ✅ Verifica que la respuesta no contenga alucinaciones
- 🔄 Reescribe tu pregunta si no encuentra información relevante
